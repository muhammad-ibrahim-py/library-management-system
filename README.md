# Library Management System

A command-line application to manage library books built with Python, using OOP principles and JSON for data persistence.

## Features

- ✅ Add new books
- ✅ View all books
- ✅ Search book by number
- ✅ Update book details
- ✅ Delete books
- ✅ Prevent duplicate book numbers
- ✅ Validate user input
- ✅ Save data to JSON
- ✅ Load data automatically on startup
- ✅ Show total number of books
- ✅ Exit safely

## Technologies Used

- **Python 3.12+**
- **Object-Oriented Programming (OOP)**
- **JSON** for data storage
- **pathlib** for file handling
- **Type hints** for clean code
